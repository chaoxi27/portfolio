如何运用本工具快速定位可能出现的舆情。

一、工具定位

游戏舆情速览工具面向游戏运营的舆情初筛场景，从批量玩家帖中定位可能需要关注的舆情信号。

适用场景：版本更新、活动上线后，快速掌握玩家的讨论焦点与负面苗头。

工具以纯规则方式在浏览器本地完成「清洗 → 找信号 → 评分」，输出按优先度排序的信号列表，作为舆情研判的入口。

二、可识别的舆情类型

工具从四个维度识别可能构成舆情的信号：

  1. 敏感与负面表述的直接命中：标题出现敏感词或负面情绪词，且与具体游戏内容共现。
  2. 负面情绪指向具体对象：负面词与角色、玩法、版本等实体在标题中共现，用以定位负面情绪所指向的对象。
  3. 高频新词：一批帖子中集中出现、但词库尚未收录的词，可能是新梗或新争议点。
  4. 游戏内容的讨论规模：已确认实体（角色、玩法）的讨论规模，用以判断讨论的量级。

三、使用流程

  1. 选定数据：选择预置示例数据，或上传含「标题、正文、平台」三字段的表格（支持 CSV 与 Excel）。
  2. 查看信号列表：信号按评分从高到低排列，优先查看排序靠前的信号。
  3. 核对信号三要素：每个信号展示规模（关联帖子数）、覆盖平台、样本标题。
  4. 判断性质：依据样本标题区分集中负面与攻略、强度等正常讨论。

四、评分与排序

评分反映信号的综合优先度，由四个维度加权合成：

声量与跨平台 ＋ 情绪强度 ＋ 情绪密度 ＋ 实体可信度与规模

评分越高，表示该信号越值得优先关注；评分用于排序，不代表负面严重程度的绝对高低。

五、工具边界与后续精判

工具为纯规则实现，负责识别可疑信号，不调用大模型。情绪与风险的精判在 Python 端由 LLM 完成。

词库（敏感词、负面词、黑话、停用词）随新数据持续补充，以降低漏判与误判。

完整流程「爬取 → 清洗 → 找信号 → 评分 → LLM 精判 → 定级 → 日报」的最终产出为 LLM 精判日报，在工具页选中示例数据后，于结果区查看对应主题的日报。
